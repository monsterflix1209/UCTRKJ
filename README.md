# 🏛️ 亞洲聯邦共和國 (RAF) 最高國務神級系統 v10.5 OMNI

基於純前端技術（HTML5 Canvas、Web Audio API、Web Crypto）構建的高科技全息戰略指揮與 AI 創生平台。

## 🌟 5 大核心功能

1. **🌐 國務 HUD & 動態雷達**：實時經濟、能源配給監控與星際戰略掃描。
2. **🪪 3D 全息證件中心**：即時生成具備 SHA-512 數位簽章之身份證件，支援 4K PNG 導出與鼠標 3D 視差。
3. **📜 AI 國務立法與辯論**：自然語言即時起草法律文件與 AI 國會模擬對抗。
4. **🚨 突發危機指揮所**：情境模擬與高層防衛方案決策分析。
5. **🧠 超 AI 機能即時創生引擎**：透過指令動態編寫並擴充全新證件與運算面板。

## 🛠️ 本地測試與執行

直接雙擊 `index.html` 即可在瀏覽器中運行完整功能。
