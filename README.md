全網頁 + Python CLI 雙核心國務系統，100% 免費部署於 GitHub Pages，無需任何付費或需額度的 API。

## ✨ 核心特色
- **零額度依賴**：完全運用瀏覽器原生 Web Crypto API 及 Python 原生 hashlib 運算。
- **高清 Canvas 證件繪製**：線上自動繪製 HD 防偽卡片，支援一鍵導出 PNG 圖檔。
- **量子級 SHA-512 數位簽章**：防偽證件真偽自動校驗。
- **多主題視覺引擎**：內建賽博霓虹、駭客矩陣、帝國尊榮等 5 大主題模式。
- **雙向 JSON 資料同步**：網頁 LocalStorage 與本地 Python 端 `raf_citizens_db.json` 無縫匯入/匯出。

## 🚀 快速發布至 GitHub Pages
1. 將本專案 Push 至 GitHub 倉庫。
2. 開啟 GitHub Repo 中的 **Settings -> Pages**。
3. Source 選擇 **GitHub Actions** 即可自動完成部署上線！
