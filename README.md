# 🏛️ 亞洲聯邦共和國（亞聯）國務公務系統
**Republic of Asian Federation (RAF) - State Administration Engine v6.5**

![Python Version](https://img.shields.io/badge/python-3.8%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)

亞洲聯邦共和國（簡稱：**亞聯**）國務院高階數位公務管理系統。提供高科技 Terminal 視覺化介面、自動化公民 AF-ID 證件簽發、DNA 生物特徵雜湊、SHA-512 防偽簽章驗證與動態主題引擎。

---

## ✨ 核心特色

- **🆔 自動化公民 ID 簽發**：生成符合亞聯編碼規範的 16 位元國籍號碼 (AF-ID)。
- **🛡️ 量子級 SHA-512 防偽驗證**：即時比對中央金鑰，防範偽造與篡改。
- **🎨 5 大主題外觀切換**：內建賽博霓虹、駭客矩陣、帝國尊榮、深海戰術與隱形特務模式。
- **📜 外交許可公文導出**：支援自動生成外交通行證，並導出為實體文字檔。
- **📦 零第三方套件需求**：採用純 Python 標準庫開發，開箱即用。
